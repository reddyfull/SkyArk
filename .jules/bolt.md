## 2024-05-24 - Measure-Object pipeline overhead and logic bugs in PowerShell
**Learning:** Using `| Measure-Object` for simple element counting incurs significant pipeline overhead and can cause logical bugs (e.g., returning 1 for an empty hashtable or failing to correctly count a single string containing delimiters). Using `Where-Object` on a string (e.g., `"a,b,c" | Where-Object {$_ -eq ','}`) evaluates the entire string as a single object instead of its individual characters.
**Action:** Replace `| Measure-Object` pipelines with direct `.Count` property access on array-wrapped objects (e.g., `@($var).Count`). For correctly identifying and counting occurrences of a delimiter within a string, replace `Where-Object` with the `-split` operator (e.g., `([string]$var -split ',').Count - 1`).
