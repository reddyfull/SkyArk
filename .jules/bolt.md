## 2024-08-22 - Replacing String Where-Object Pipelines with Direct Array Methods
**Learning:** In PowerShell, piping a scalar string to `Where-Object` (e.g. `$string | Where-Object {$_ -eq ','}`) passes the entire string as a single object, failing to evaluate characters or split elements, which silently returns `$null` (or count 0). Additionally, piping array objects through `Measure-Object` creates significant pipeline overhead.
**Action:** Always convert comma-separated strings to arrays via the `-split` operator (`[string]$string -split ','`). To filter or count, wrap the resulting array evaluation in an array cast and use native property accessors without pipeline usage, like `@(@($array) -like '*-Thr*').Count` or `$array.Count - 1`. This corrects logic bugs and improves loop performance by nearly 35x.
