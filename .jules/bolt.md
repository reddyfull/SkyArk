## 2024-10-27 - [Performance & Logic Fix: PowerShell `Measure-Object` and string filtering]
**Learning:** In PowerShell, using `Where-Object` directly on a single string (e.g., `"a,b,c" | Where-Object {$_ -eq ','}`) evaluates the entire string as a single object, returning nothing. This leads to silent logic bugs when counting character occurrences. Additionally, using `Measure-Object` for simple array counting introduces significant pipeline overhead.
**Action:** Replace string pipeline filtering with the `-split` operator (e.g., `([string]$var -split ',').Count - 1`) for character counting, and wrap array filtering operators in `@()` combined with `.Count` (e.g., `@(@([string]$var -split ',') -like '*-Thr*').Count`) to fix logic bugs and improve performance by avoiding `Measure-Object`.
