## 2024-07-13 - Pipeline Overhead and String Counting in PowerShell
**Learning:** Using `| Measure-Object` for counting elements in arrays or strings incurs significant pipeline overhead (~2300ms vs ~15ms for 1000 items). Furthermore, using pipeline filtering (e.g., `| Where-Object {$_ -eq ','}`) on a scalar string evaluates the entire string as a single object, incorrectly returning a count of 0 or 1.
**Action:** Replace `| Measure-Object` pipelines with direct `.Count` property access on array-wrapped objects. For string counting based on delimiters or patterns, use `.Split(',')` followed by `.Count`, or wrap the object in an array and use native filtering operators (e.g., `@(@($var) -like 'pattern').Count`) to handle nulls, scalars, and arrays safely without pipeline overhead.
