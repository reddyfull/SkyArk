## 2024-05-24 - PowerShell Pipeline vs Direct Property Performance
**Learning:** In PowerShell, using `Where-Object` and `Measure-Object` inside loops causes severe performance bottlenecks due to pipeline initialization and object wrapping overhead. Further, using `Where-Object {$_ -eq ','}` on a single string to count characters is logically flawed, as it evaluates the entire string as one object and returns empty instead of character counts.
**Action:** Replace `($variable | Measure-Object).Count` with direct property access `@($variable).Count` to avoid pipeline overhead while safely casting `$null` to arrays. For counting character occurrences in strings, replace pipeline filtering with string split operations: `([string]$string -split ',').Count - 1`. This safely handles `$null` and correctly counts occurrences.
