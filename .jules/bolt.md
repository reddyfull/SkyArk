## 2024-05-18 - [Fix array behavior in PowerShell Pipelines]
**Learning:** In PowerShell, using `Where-Object` on a single string (scalar value) fails because the string is treated as a single item passed through the pipeline, so a condition like `$_ -eq ','` will never be true. Using `-like` and `-eq` works differently on single objects vs arrays. `($var | Where-Object {$_ -eq ','} | Measure-Object).Count` produces an incorrect output `0` on strings like `"A,B,C"` rather than counting the occurrences.
**Action:** Use native string methods like `.Split(',')` followed by array count `.Count - 1` or explicitly wrap the string split result in an array and use `-like` (e.g., `@($parts -like '*-Thr*').Count`). This not only fixes logical bugs with strings but significantly speeds up processing by bypassing the slow PowerShell pipeline (a >18x speedup).
