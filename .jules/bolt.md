## 2024-05-24 - [Measure-Object Bottleneck in PowerShell]
**Learning:** `Measure-Object` is a heavy pipeline operation in PowerShell. Wrapping a collection with array notation `@($var).Count` or calling `$var.Count` is over 60x faster (37ms vs 2300ms for 1000 iterations). In `AWStealth.ps1`, `Where-Object | Measure-Object` combinations are particularly slow, but must be carefully replaced to handle string scalar matching correctly since strings don't yield pipeline elements when split inside a pipeline. The safest alternative is `$_var.Split(',').Count - 1` and `@(@($var.Split(',')) -like '*-Thr*').Count`. Also found a bug in `AWStealth.ps1:893` where `$inlineRolePoliciesCounter | Measure-Object` is measured instead of `$inlineRolePolicy`.
**Action:** Replace `| Measure-Object` with array length evaluation `.Count` for element counting, especially in loops and metric collections. Use string manipulation when dealing with comma-separated string property counts instead of piping characters.
