## 2024-09-13 - Optimize PowerShell string counting pipelines
**Learning:** `($_.PolicyName | Where-Object {$_ -eq ','} | Measure-Object).Count` has massive pipeline overhead and returns incorrect logic (evaluating entire string as a single object) whereas string splitting is significantly faster and correct. Wrapping string casting/splitting in arrays with native operators effectively maintains semantics, gracefully manages `$null` values, and executes substantially faster than PowerShell's pipeline operators.
**Action:** Replace `Where-Object {$_ -eq ','} | Measure-Object` with `([string]$var -split ',').Count - 1` and replace `Where-Object {$_ -like '*-Thr*'} | Measure-Object` with `@(@([string]$var -split ',') -like '*-Thr*').Count` for O(N) performance avoiding the object overhead of pipes.
