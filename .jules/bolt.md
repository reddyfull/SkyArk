## $(date +%Y-%m-%d) - Fix logic bug and performance bottleneck in AWStealth counting string occurrences
**Learning:** Using `Where-Object {$_ -eq ','} | Measure-Object` on a single string in PowerShell doesn't count the occurrences of the character. Instead, it evaluates the entire string as a single object against the condition, failing to match. This caused a logic bug in AWStealth where `$countPolicyNames` was always evaluated to 0. Similarly, `$countPoliciesFromGroups` evaluated to 1 if the string contained `-Thr`, but failed to accurately count if there were multiple `-Thr` matches, because the string itself matched the `*-Thr*` pattern once.
**Action:** Use the `-split` operator (`([string]$_.PolicyName -split ',').Count - 1`) to properly identify and count occurrences of delimiters in a string. This natively parses the string properly, fixes the logic bug, and bypasses the pipeline `Where-Object | Measure-Object` overhead to improve performance safely.
