## 2024-05-24 - Optimize PowerShell array filtering by removing pipelines
**Learning:** In PowerShell, using `Where-Object | Measure-Object` for simple filtering and counting introduces significant pipeline overhead. Direct string methods (like `.Split()`) or Regex matches are faster but have different semantics when elements are missing. Wrapping the left-hand operand in an array and using PowerShell's native array filtering operators (`@(@($var) -eq 'val').Count`) preserves exact pipeline-like behavior (handling `$null`, scalars, and arrays correctly) while avoiding the pipeline overhead, improving the counting execution time from hundreds of milliseconds to roughly 10-20 milliseconds for 1000 iterations.
**Action:** When filtering or counting strings or primitives in arrays in performance-sensitive loops, replace `Where-Object | Measure-Object` with `@(@($var) -operator 'value').Count` to drastically reduce overhead without introducing breaking behavior.
