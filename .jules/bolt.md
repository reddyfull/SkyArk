## 2024-07-24 - [Avoid PowerShell Pipeline Overhead for Fast Counting]
 **Learning:** Using `Measure-Object` for simple array/scalar counting creates a massive performance bottleneck due to PowerShell's pipeline overhead. Even more severe is combining `Where-Object` with `Measure-Object` in loops. For strings, native methods like `.Split().Count - 1` are 25x faster. For array items, safely avoiding `$null` or scalar typing issues can be achieved by explicitly wrapping variables (`@($var)`) and using native property accessors `.Count` or array filtering operators (like `-like` / `-eq` which do not collapse items).
 **Action:** For performance optimization, avoid pipeline overhead (`| Measure-Object`, `| Where-Object`) on inner loops. Use explicit array wrapping and property access (`@($var).Count`) instead of pipelines, and rely on native string/array methods where semantics permit, while preserving precise string manipulation logic.
