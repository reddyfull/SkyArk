## 2024-05-24 - [Avoid Pipeline Overhead in PowerShell Logic]
**Learning:** In PowerShell, using `Where-Object` on a single string evaluating as an array and piping to `Measure-Object` is slow and can cause bugs when trying to count delimiter matches. For instance, `($string | Where-Object {$_ -eq ','} | Measure-Object).Count` returns 0 for a comma-separated string because it treats the whole string as one object that does not equal `,`.
**Action:** Replace `Where-Object` and `Measure-Object` with array operators or `-split` for counting delimiter matches. Use `([string]$var -split ',').Count - 1` to count commas, and `@(@([string]$var -split ',') -like '*-Thr*').Count` for matching substrings within delimited parts. This is much faster and corrects semantic logic errors.
