## 2024-05-23 - Pipeline overhead when counting string parts
**Learning:** In PowerShell, using `Where-Object` on a pipeline output of split strings (e.g., `($string | Where-Object {$_ -eq ','} | Measure-Object).Count`) can be exceptionally slow due to pipeline overhead, especially in loops. Additionally, `Where-Object` operates over single objects, so treating a string as a collection requires implicit behaviour that can be inefficient. Replacing it with direct string array operators or `String.Split()` methods (e.g., `([string]$string -split ',').Count - 1` and `@([string]$string -split ',' -like '*-Thr*').Count`) can provide massive speedups while safely handling `$null` values.
**Action:** Use native array operators or `-split` for counting string parts instead of `Where-Object | Measure-Object` inside loops.
