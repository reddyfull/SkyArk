## 2024-05-18 - Avoid Pipeline Overhead for Object Counting in PowerShell
**Learning:** In PowerShell, using `| Measure-Object | Select-Object -ExpandProperty Count` or `($var | Measure-Object).Count` introduces massive pipeline overhead, especially inside loops. Additionally, piping primitive strings through `Where-Object` (e.g. `$string | Where-Object {$_ -eq ','}`) evaluates the whole string as a single object, returning nothing and creating logic bugs.
**Action:** Use native properties like `$var.Count` (if it's an array/collection) or force an array context (`@($var).Count`) to count elements safely and directly without pipeline overhead. For string delimiter counting, use the `-split` operator (`($string -split ',').Count - 1`). For filtering arrays of custom objects, use `$var | Where-Object { ... }` but access `.Count` directly on the result instead of piping to `Measure-Object`.
