## 2025-02-18 - Avoid Pipeline Overhead for Object Counting
**Learning:** Using `| Where-Object | Measure-Object` for simple filtering and counting operations on scalars or small arrays incurs massive pipeline overhead in PowerShell (~2000ms vs ~35ms for 10000 iterations). Additionally, logic like `Where-Object {$_ -eq ','}` on a single string actually returns `$null` because the string is evaluated as one object (it's not split into characters).
**Action:** Replace `| Where-Object {$_ -operator 'value'} | Measure-Object` pipelines with native array filtering operators wrapped in an array cast: `@(@($var) -operator 'value').Count`. This drastically improves performance while safely maintaining exact original evaluation semantics for nulls, scalars, and arrays without throwing fatal method exceptions.
