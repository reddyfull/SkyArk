## 2025-02-14 - Optimize Pipeline Overhead in AWStealth PowerShell Script
**Learning:** In PowerShell, using pipelines (`|`) with `Measure-Object` and `Where-Object` on arrays and scalars can be incredibly slow because of internal pipeline enumeration overhead. `Where-Object` and `Measure-Object` are very common but inefficient ways to count and filter arrays.
**Action:** To dramatically improve performance while ensuring correctness across arrays, scalars, and `$null` variables, replace `$($var | Measure-Object).Count` with the native cast `@($var).Count`. For counting elements matching a condition, replace `$($var | Where-Object {$_ -eq ...} | Measure-Object).Count` with `@(@($var) -eq ...).Count`. This preserves all semantics, avoiding fatal pipeline errors while massively boosting script throughput.
