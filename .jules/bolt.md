## 2024-10-24 - [Avoid `Measure-Object` for simple array operations in PowerShell]
**Learning:** Using `$array | Measure-Object` in PowerShell is incredibly slow due to pipeline overhead, sometimes taking ~2-3 seconds for just 1000 iterations. It's much more performant to use the native `.Count` property directly on the variable or wrap it in an array to handle potential scalars (`@($array).Count`). Furthermore, for string analysis, `$string | Where-Object {$_ -eq ','} | Measure-Object` doesn't split the string by comma, it evaluates the entire string as one element, returning 0 unless the string is exactly `,`. Using `.Split(',').Count - 1` is both highly performant and correct.
**Action:** When working on PowerShell codebases, aggressively replace `Measure-Object` and `Where-Object` in pipelines with direct `.Count` property accesses and native array filtering operators like `-like` wrapped as `@(@($var) -like 'pattern').Count` to ensure significant performance and correctness gains.
