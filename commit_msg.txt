⚡ Bolt: Optimize string counting in AWStealth

💡 What: Replaced `Where-Object | Measure-Object` pipelines with the `-split` operator for counting string delimiters in `AWStealth.ps1`.
🎯 Why: The original pipeline approach was failing to count occurrences correctly because a single string passed to `Where-Object` is evaluated as one object. Furthermore, pipelines add substantial performance overhead in loop executions.
📊 Impact: Fixes a bug in identifying users with direct vs group privileges, and improves execution time for this counting operation by ~16x.
🔬 Measurement: Run a test counting logic loop and observe the output correctness and duration.
